# 🙌 Contributing to AKSHARA 
Thank you for considering contributing to this project! 🎉 Whether it's fixing bugs, improving the UI, or adding new features, your help is appreciated.  

## 🚀 Getting Started  
1. **Fork the Repository**  
2. **Clone the Project**  
```bash
git clone https://code.swecha.org/Abhijeeth/akshara-duolingo_for_indiclanguages
cd akshara-duolingo_for_indiclanguages
```  
3. **Create a Branch**  
```bash
git checkout -b feature/your-feature-name
```  
4. **Install Requirements**  
```bash
pip install -r requirements.txt
```  
5. **Start the App**  
```bash
 run main.py
```  

## 📌 Contribution Guidelines  
### ✅ What You Can Contribute:  
- 🐞 Bug fixes  
- ✨ New features or export formats (e.g., PDF, Word, TXT)  
- 💅 UI/UX improvements  
- 🧪 Tests or performance enhancements  
- 📝 Documentation (README, docstrings, etc.)  

### 🧹 Code Style:  
- Use descriptive commit messages  
- Follow [flutter](https://docs.flutter.dev/get-started/fundamentals) for flutter code  
- Keep code modular and commented  

## 🧪 Testing  
Ensure your code:  
- Does not break existing features  
- Works across supported platforms  
- Is tested locally before pushing  

## 📤 Submitting Changes  
1. Commit your changes:  
```bash
git commit -m "Add: feature/bug fix description"
```  
2. Push to your fork:  
```bash
git push origin feature/your-feature-name
```  
3. Create a Merge Request (MR) on GitLab with a short description and link to any related issue.  

## 🙏 Thank You!  
We’re excited to have you contribute and grow this project with us. 💚
